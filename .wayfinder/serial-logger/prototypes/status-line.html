Status line during a 30-minute silence

Throwaway prototype. The device sends two lines, goes quiet for 29 minutes, then sends one more. Each pane shows what the terminal looks like during the quiet stretch. Run any of them live with the command underneath.

Variant 1 — one-line footer, redrawn in place

The stream scrolls normally; a single dim line pinned at the bottom counts up.

2026-09-10T14:00:01.000+01:00 BOOT OK
2026-09-10T14:00:02.000+01:00 TEMP=21.4 HUM=48
⏳ 14m since last line · 2 lines · 23 B · session-2026-09-10.log

go run /tmp/proto/main.go 1

Variant 2 — two-line block, labelled

Adds the port, the adapter, the line settings and the full log path. More to read, nothing to guess.

2026-09-10T14:00:01.000+01:00 BOOT OK
2026-09-10T14:00:02.000+01:00 TEMP=21.4 HUM=48
┌ /dev/ttyUSB0  FTDI TTL232R  115200 8N1
└ waiting 14m · 2 lines · 23 B · ~/.local/state/smart-device-logger/session-2026-09-10.log

go run /tmp/proto/main.go 2

Variant 3 — no status line; a marker in the stream every 10 minutes

Nothing is redrawn, so the marker survives a pipe and lands in the log file too. You lose the live counter.

2026-09-10T14:00:01.000+01:00 BOOT OK
2026-09-10T14:00:02.000+01:00 TEMP=21.4 HUM=48
-- no data for 10m --
-- no data for 20m --
2026-09-10T14:00:03.000+01:00 TEMP=21.6 HUM=47

go run /tmp/proto/main.go 3
